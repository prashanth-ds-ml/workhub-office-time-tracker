# Project Overview

WorkHub v1.1 is a Python desktop office time tracker centered on a Tkinter app and a local FastAPI backend. The desktop app is the primary product surface.

## Document Map

- `home.md` – project overview
- `README.md` – current setup and run instructions
- `commands.md` – command reference for the desktop app and backend
- `BUILD_ORDER.md` – implementation order for the Tkinter-first v1.1 scope
- `progress.md` – recent milestones
- `decisions.md` – architecture and product decisions
- `AGENTS.md` – agent-specific working notes
