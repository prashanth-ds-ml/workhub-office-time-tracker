WorkHub Reminder: one-time setup (2 minutes)
=============================================

This opens WorkHub when you start or wake your laptop. It also reminds you
to punch in and out on working days only.

Install
-------
1. Extract WorkHubReminder.zip (right-click it, then Extract All).
2. Open the extracted folder and double-click WorkHubReminder.exe.
3. If Windows shows a blue "Windows protected your PC" screen, click
   "More info", then "Run anyway". The file is unsigned, which is why
   Windows warns about it - it's still the same app from this zip.
4. You'll see an "installed" popup and WorkHub will open in your browser.
   That's all. You can delete the downloaded files afterwards - it copies
   itself to a permanent folder automatically.

Reminders (IST, working days only; none on holidays)
------------------------------------------------------
- Punch in:            10:30 AM - 11:00 AM
- Punch out:             5:30 PM -  6:00 PM
- Punch out (half days): 2:30 PM -  3:00 PM

The popup shows once per window. Just dismiss it if you've already punched.

Check it works
---------------
Restart your laptop. WorkHub should open by itself a few seconds after you
sign in.

Problems? Close your laptop lid and reopen it. WorkHub should open again
after about 15 seconds. If it doesn't, message me.

Updating to a new version
-------------------------
Double-click Uninstall.bat from the old package first, then run the new
WorkHubReminder.exe.

Uninstall
---------
Double-click Uninstall.bat (in this folder). It stops the app, removes its
startup entries and deletes it. Nothing else is left behind.
